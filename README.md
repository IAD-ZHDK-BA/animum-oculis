# MUI 26 — Technical Prototype

This is the template project for the Mobile User Interface 2026 course. It contains
blueprint material for you to build on. Make the project your own: add files,
remove files, change them. 
Always commit your changes with git (e.g. GitHub Desktop) so you always have a state to return to.
For the final submission, you are not required to provide an app icon.

## Getting it to run

1. Clone the repository to your local machine (not in iCloud, Dropbox, e.g.)
2. Sign in with your Apple Account in Xcode Settings, if you have not already.
3. Pair your Apple Vision Pro, if you have not already.
4. In Xcode, open **Signing & Capabilities** and set *Team* to the name you see
   after signing in with your Apple Account.
5. Build and run with ⌘R, or from the menu bar.
6. Happy coding!

**If both team members want to build on a real device:** a bundle identifier can only
be registered to one Apple Account. So either you both sign in with the same
Apple Account, or the second one changes the bundle identifier in *Signing &
Capabilities* to something unique. If you change it, do not commit that change —
keep it on your own machine.

## Questions and issues

Email the instructor, and include:

- what you were trying to do,
- the error or unexpected behaviour you are getting,
- every step you took to get there.

Commit and push that work first, so it can be inspected remotely.
